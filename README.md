\# Kapture Finance Voice Agent



A Voice AI collections agent built using Vapi AI and Node.js.



\## Features



\- Customer verification

\- Loan details lookup

\- Promise to Pay

\- Payment link generation

\- Call escalation



\## Tech Stack



\- Node.js

\- Express.js

\- Vapi AI

\- OpenAI GPT-4o

\- Ngrok
